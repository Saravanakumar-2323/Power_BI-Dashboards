# 📊 Power BI Dashboards

A collection of interactive **Power BI dashboards** created to analyze and visualize data across different domains. These projects demonstrate practical skills in **Data Analysis, Data Visualization, Power BI, and Dashboard Development**.

## 📁 Dashboards Included

### 🗳️ 1. Election Dashboard
An interactive dashboard designed to analyze election-related data and present important insights through visualizations.

**Key Areas:**
- Election data analysis
- Candidate and party performance
- Vote distribution
- Geographical analysis
- Interactive filters and slicers

**File:** `Election Dashboard.pbix`

---

### 👥 2. HR Analytics Dashboard
A dashboard focused on analyzing employee and HR-related data to identify workforce trends and patterns.

**Key Areas:**
- Employee analysis
- Department-wise insights
- Employee demographics
- Attrition analysis
- Job role and performance analysis
- Interactive filters and visualizations

**File:** `HR - Analytics Dashboard.pbix`

---

### 🎓 3. Student Performance Dashboard
An interactive dashboard for analyzing student academic performance and identifying performance trends.

**Key Areas:**
- Student performance analysis
- Subject-wise performance
- Score distribution
- Attendance analysis
- Student-level insights
- Interactive slicers and charts

**File:** `Student Performance Dashboard.pbix`

---
